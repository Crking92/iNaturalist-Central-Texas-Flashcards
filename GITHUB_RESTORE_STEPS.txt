GITHUB RESTORE STEPS

1. Open the folder named UPLOAD_TO_GITHUB_ROOT.
2. Upload everything inside that folder to the ROOT of your GitHub repository.
   The root means index.html should be visible immediately when you open the repo, not inside another folder.
3. Confirm the repo has this structure:

   index.html
   .nojekyll
   README.md
   data/daily_data.js
   data/master_plants.json
   data/host_numbers.csv

4. In GitHub Pages settings, publish from the main branch and root folder.
5. After GitHub finishes rebuilding, hard-refresh the site.

Do not upload KEEP_ON_DESKTOP_UPDATE_FOLDER to GitHub unless you intentionally want the private updater there.
